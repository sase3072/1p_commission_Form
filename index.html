    조작 가이드 — 번호를 캔버스와 맞춰 보세요

    작업 내용은 브라우저에 자동 저장되어 새로고침해도 유지됩니다
    1 성격 키워드
    • 좌측 패널에서 문구와 색상을 수정합니다.
    • 일괄 색상 적용으로 3개를 한 번에 맞춥니다.
    • 토글을 끄면 캔버스에서 사라집니다.
    2 한마디 말풍선
    • 1줄 / 2줄 정렬과 아이콘 종류를 고릅니다.
    • 말풍선 아이콘 클릭 시 색상이 바뀝니다.
    3 메인 두상 & 스티커
    • 점선 영역 더블 클릭으로 업로드합니다.
    • 드래그 이동, 휠로 확대·축소합니다.
    • 스티커는 클릭 시 정렬 툴바가 뜨고, Shift+클릭으로 여러 개를 선택합니다.
    4 표정 슬롯
    • 크기가 같은 이미지는 위치·확대가 동기화됩니다.
    • 크기가 다르면 각각 독립 조작됩니다.
    • 우측 하단을 클릭해 표정 이름을 씁니다.
    5 유틸리티 패널
    • 자석 스냅을 켜면 스티커가 가장자리·중앙선에 붙습니다.
    • 캔버스 너비·글씨 크기를 조절합니다.
    • PNG·JPEG로 완성본을 저장합니다.
    • 자세한 내용은 사용 설명서에서 확인하세요.

    사용 설명서

    1. 이미지 업로드 (두상 · 표정)

    • 점선 박스를 더블 클릭하면 이미지 업로드 창이 열립니다.
    • 업로드 후 드래그로 위치를, 마우스 휠로 확대·축소를 조절합니다.
    • 표정 슬롯은 가로·세로 크기가 완전히 같은 이미지끼리 위치와 확대가 자동으로 동기화됩니다. 크기가 다르면 각각 따로 조작됩니다.
    • 표정 슬롯 우측 하단을 클릭해 표정 이름을 입력할 수 있습니다.

    2. 스티커 / 데코

    • 우측 패널 '스티커 추가 선택'으로 이미지를 올리면 캔버스 위에 스티커로 추가됩니다.
    • 드래그로 이동, 모서리 파란 사각형 손잡이로 크기 조절, 우측 상단 원형 손잡이로 회전합니다.
    • 마우스를 올리면 나타나는 × 버튼으로 삭제합니다.
    • 스티커를 클릭하면 위에 정렬 툴바가 떠서 좌/우/상/하/중앙 정렬을 바로 적용할 수 있습니다.
    • Shift(또는 Ctrl)+클릭으로 여러 스티커를 함께 선택하면, 선택한 것들끼리 나란히 정렬됩니다.

    3. 자석 스냅 정렬

    • 우측 패널 맨 위의 토글로 켜고 끌 수 있습니다(기본 켜짐).
    • 켜져 있으면 스티커를 드래그할 때 캔버스의 가장자리와 가로·세로 중앙선에 가까워질 때 자동으로 달라붙고, 분홍색 가이드선이 표시됩니다.

    4. 성격 키워드 & 말풍선

    • 좌측 패널에서 키워드 문구와 색상을 각각 지정하거나, 일괄 색상 적용으로 한 번에 맞출 수 있습니다.
    • 말풍선은 1줄 / 2줄 정렬과 마이크 / 인용구 / 표정 아이콘을 고를 수 있습니다.
    • 말풍선 왼쪽 아이콘을 클릭하면 아이콘 색상이 바뀝니다.
    • 키워드·말풍선·표정 슬롯은 각각 토글로 숨길 수 있습니다.

    5. 이름 · 프로필 박스 · 컬러 팔레트 · 설명

    • 이름과 원문 이름은 캔버스에서 직접 클릭해 입력합니다.
    • 프로필 박스 추가로 성별·나이·신장 등의 칸을 늘릴 수 있습니다(최대 6개).
    • 컬러 팔레트 추가로 색상 칸을 늘리고, 각 칸은 클릭해 색을 고르거나 컬러 코드를 직접 입력할 수 있습니다.
    • 외관 설명은 '+ 외관 설명 줄 추가'로 늘리고, 글씨 크기는 우측 슬라이더로 조절합니다.

    6. 저장 & 단축키

    • 모든 작업은 기기 브라우저 안에 자동 저장되어 새로고침해도 유지됩니다.
    • PNG는 배경 손실 없이, JPEG는 더 가벼운 용량으로 저장됩니다. 저장 시 가이드·버튼 등은 이미지에 나오지 않습니다.
    • M 키(또는 화면 아래 버튼)로 좌우 패널을 숨겨 캔버스를 넓게 볼 수 있습니다.
    • Esc 키로 가이드나 이 설명서를 닫을 수 있습니다.
    • 화면이 좁거나 모바일에서는 캔버스가 자동으로 축소되어 보이며, 저장되는 이미지는 축소와 무관하게 항상 원본 해상도로 저장됩니다.
    • 전체 데이터 초기화는 되돌릴 수 없으니 주의하세요.
